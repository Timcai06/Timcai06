# Mathematical modeling figures

Built by `scripts/build_modeling.py` from Tim's chosen paper figures (all referenced by their paper, all generated by Python). In each project's fold the first figure is the lead, shown full width at its own proportions (`<slug>-1.png`). Supporting figures stay readable: wide ones (aspect ≥ 2.0) get a full row; the others are paired two per row on white cards of a shared shape so heights align; an odd one is paired with a project info cell.

Source of truth: `~/Desktop/数模论文插图/索引.md` (caption, generator script, original path). Local repositories: `~/School/数模/`. To change the selection or the lead, edit `PROJECTS` in the script (first figure = lead) and re-run it.

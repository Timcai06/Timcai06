# Pixel Lab — asset history

Created with the built-in image generation tool, using the approved pixel-workstation concept as a visual reference. These are original concept illustrations, not screenshots or evidence of product features. Source PNGs are kept unchanged.

## Generation prompts

Shared direction: production-ready standalone landscape pixel-art illustration, 2:1 composition; refined detailed pixel art, nighttime indigo, lavender and warm amber desk lighting; reference the approved design's art direction; edge-to-edge illustration without GitHub chrome, sidebar or card frames.

- `hero.png`: Moonlit mountains and lake beyond a window, cozy programmer desk, right-hand CRT with a glowing neural network, books, notebook, plants, amber lamp. Large ivory pixel lettering “TIM CAI”, smaller “AI systems. Thoughtfully built.” Dark window behind the text.
- `sciscope.png`: Glowing blue globe on a brass pedestal, floating papers connected by delicate evidence lines, books and starry navy backdrop. No text requested.
- `pulsegraph.png`: Retro CRT and instrumentation with blue, violet and amber training curves, amber indicator lights, nighttime laboratory. No text requested.
- `bdi.png`: Elevated arch bridge across a lake at violet dusk, orange twilight, evergreen mountains, tiny drone and fine inspection overlays. No text requested.
- `educanvas.png`: Cozy desk, open laptop displaying an abstract learning canvas of diagrams, image and audio shapes, books, plants and warm window light. No text requested.

## Current revision

`background.png` is the unchanged generated background used behind the editor in `assets/editor/workspace.svg`. The edit removes the hero lettering and leaves a quiet lake/night scene, desk lighting and edge details. The former hero and four project illustrations are retained as earlier design assets; the profile no longer displays them as product covers. SciScope, EduCanvas and PulseGraph now reuse these scenes only as backgrounds behind project editor windows.

The editor artwork is generated by `scripts/build_profile.py`. Its SVGs embed the background and use native SVG text/shapes, with no JavaScript, foreignObject or external resources. Editor controls are visual artwork; real navigation and project links are in README HTML.

## Rebuild

From the repository root, run `python3 scripts/build_profile.py` (editor SVGs) and `python3 scripts/build_motion.py` (work key visuals). Preview the README in VS Code or on GitHub.
